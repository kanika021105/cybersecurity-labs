# File Integrity Monitoring System

A cybersecurity tool that detects unauthorized file modifications using SHA-256 hashing.

## Features

- SHA-256 hashing
- Baseline creation
- Integrity verification
- Tamper detection

## Technologies

- Python 3
- hashlib

## Use Cases

- File monitoring
- Tamper detection
- Security auditing
- Incident response
