# Security Monitoring Dashboard

A cybersecurity monitoring project built using Python.

## Modules

### Log Analyzer
Detects:
- warnings
- errors
- suspicious activity

### Login Detector
Detects:
- failed logins
- brute-force attempts
- suspicious IP addresses
